# OMX 작업실 — 카메라 점검과 시범 검토

로봇에 연결하거나 동작 명령을 보내지 않는 로컬 웹 도구입니다. 카메라 미리보기는 브라우저 권한을 허용해야 하며, 파일은 사용자가 직접 선택합니다. 브라우저는 JPEG 손상 경고를 검사하지 못하고 화면과 장치가 보고한 설정만 보여줍니다.

## 내려받기

Python 3이 필요합니다. Git으로 이 저장소를 받을 때 아래처럼 설정하면 큰 데이터 ZIP을 자동으로 받지 않고 대시보드 코드만 사용할 수 있습니다. 이미 저장소를 받았다면 이 단계는 건너뜁니다.

**Windows PowerShell**

```powershell
$env:GIT_LFS_SKIP_SMUDGE = "1"
git clone https://github.com/Youngkwon-Lee/omx-baseline-v1.git
Remove-Item Env:GIT_LFS_SKIP_SMUDGE
cd omx-baseline-v1\omx-dashboard
```

**macOS / Linux**

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/Youngkwon-Lee/omx-baseline-v1.git
cd omx-baseline-v1/omx-dashboard
```

이 명령은 시범 영상이나 학습 모델을 내려받지 않습니다. 카메라를 확인하려면 카메라가 연결된 컴퓨터에서 실행하고, 영상을 검토하려면 별도로 영상을 내려받거나 해당 컴퓨터에 복사하세요. Git이 없으면 GitHub 저장소 화면에서 **Code → Download ZIP**으로 코드를 받을 수 있습니다. ZIP에 원본 데이터의 LFS 포인터가 포함될 수 있지만 대시보드 실행에는 필요하지 않습니다.

## 실행

이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행한 뒤 브라우저에서 `http://127.0.0.1:8765/`를 엽니다. macOS/Linux에서는 Python 명령이 `python3`일 수 있습니다. Windows에서는 `start-dashboard.bat`을 실행해도 됩니다. 서버를 중지하려면 터미널에서 Ctrl+C를 누릅니다. 주소의 `127.0.0.1`은 각자 컴퓨터 자신을 의미하므로 다른 사람에게 그대로 공유하는 원격 접속 주소가 아닙니다. 포트가 이미 사용 중이라면 `8766` 등 다른 포트로 바꾸고 브라우저 주소도 같은 번호로 여세요.

로봇에 연결된 컴퓨터에서 실행해야 그 컴퓨터의 카메라를 선택할 수 있습니다. 브라우저 카메라 권한과 운영체제 장치 권한이 필요하며, 다른 앱이 카메라를 점유한 경우 먼저 닫습니다. 카메라 찾기 → 브라우저 권한 허용 → 상단·손목 각각 장치 선택 및 연결 → 화면 방향 확인 순서로 진행합니다. 출력되는 FPS는 장치가 보고한 값으로, 실제 프레임 전송 속도 검증은 아닙니다.

## 검토

데이터셋 이름과 에피소드 번호는 사람이 지정하며, 상단·손목 영상도 직접 선택합니다. 여러 에피소드가 한 파일에 묶였다면 플레이어에서 해당 장면을 찾아야 합니다. 자동으로 에피소드를 분리하거나 실제 성공 여부를 판단하지 않습니다. 함께 재생은 상단 영상의 현재 시점에서 시작하도록 맞추는 편의 기능이며, 프레임 단위 동기화를 보장하지 않습니다. 브라우저가 AV1 등의 영상 코덱을 지원해야 재생됩니다.

판정은 이 브라우저의 localStorage에 저장됩니다. 같은 데이터셋 이름·에피소드 번호의 저장은 기존 판정을 갱신합니다. JSON 내보내기로 백업하고 다른 브라우저에서 가져올 수 있으며, 가져올 때 기존 키는 덮어쓰지 않습니다. 원본 영상, 로봇 데이터, 학습/검증 분할은 변경하지 않으며, Google Drive나 Hugging Face에 자동 업로드하지 않습니다. 브라우저 저장소를 지우면 백업하지 않은 기록이 사라집니다.
