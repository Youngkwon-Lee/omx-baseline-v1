# OMX baseline v1

This repository contains the original OMX robot demonstration dataset archive shared by a team member.

- Robot: `omx_follower`
- Episodes: 50; frames: 14,644; frame rate: 30 fps
- Contents: action and observation data in Parquet, metadata, and top and wrist camera videos.
- The archive is stored with Git LFS. Install Git LFS and run `git lfs pull` after cloning, then extract the ZIP to use the original dataset directory.
- This archive contains demonstration data; it does not include trained model weights or training code.

Dataset reuse terms and provenance have not yet been documented. No license is specified in this repository.
